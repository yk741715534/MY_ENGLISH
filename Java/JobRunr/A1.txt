各框架详细解析
1. XXL-Job

定位：轻量级、易用、开箱即用，是当前国内最流行的开源选择。

优点：

上手简单：部署一个调度中心，引入依赖即可使用，控制台功能全面。

调度与执行分离：架构清晰，调度器负责触发，执行器负责执行，易于扩展。

故障转移：任务路由策略丰富（轮询、故障转移等）。

弹性扩缩容：执行器自动注册，动态增减节点无感。

日志完整：提供完整的执行日志和运行报告。

缺点：在大规模、超高性能（每秒数万次调度）或需要复杂工作流编排的场景下，可能不是最优选。

总结：“中庸之道”的首选，能满足 90% 以上的业务调度需求，社区支持好，问题容易解决。

2. PowerJob

定位：面向未来的“全能型”分布式任务调度与计算框架。

优点：

功能强大：支持多种任务类型，特别是其工作流（DAG）编排和MapReduce模型，非常适合需要分治聚合的分布式计算场景。

性能优异：采用 Akka 架构，设计上支持海量任务。

开放生态：支持外部任务（如 K8s Job）、OpenAPI。

可观测性好：控制台监控指标丰富。

缺点：相比 XXL-Job 稍重，概念更多，学习曲线略陡。

总结：如果你需要超越简单定时触发，有复杂工作流、大数据批处理等需求，PowerJob 是比 XXL-Job 更强大的选择。

3. Apache DolphinScheduler

定位：分布式易扩展的可视化 DAG 工作流任务调度平台。

优点：

以工作流为核心：可视化拖拽编排复杂的任务依赖关系，这是其与上述所有框架最本质的区别。

多租户：支持企业多团队、多项目使用。

支持多种任务类型：Shell、SQL、Spark、Flink、DataX 等，与数据开发场景无缝结合。

高可靠性：去中心化的 Master/Worker 架构，支持高可用。

缺点：部署和运维相对复杂，如果只是想做简单的定时调用 HTTP 接口，有点“杀鸡用牛刀”。

总结：数据领域、ETL 管道、复杂业务流程编排的绝佳选择。如果你的核心是调度“数据任务”，而非“业务服务方法”，选它。

4. Quartz (集群模式)

定位：Java 定时任务的事实标准，一个“库”而非“平台”。

优点：

极度灵活：作为库嵌入到任何Java应用中，可控性强。

标准：API 设计经典，生态丰富。

缺点：

无控制台：需要自行开发管理界面。

集群基于数据库锁：性能有瓶颈，大规模集群下竞争激烈。

功能单一：仅提供最核心的调度触发，分片、故障转移、弹性扩容等需自行实现。

总结：轻量级单体或小型应用，或作为其他调度框架的底层内核。在新项目中选择 Quartz 集群直接使用的场景越来越少。

5. ShardingSphere-ElasticJob

注意：老 Elastic-Job 已归档，其精神续作是 ShardingSphere-ElasticJob。它继承了分片、弹性等核心思想，并整合到 ShardingSphere 生态中，定位更偏向于“分布式数据库调度治理”。如果已经在用 ShardingSphere 生态，可以考虑。

6. SchedulerX (阿里云)

定位：阿里云提供的企业级、全托管、高可靠的分布式任务调度服务。

优点：

免运维：无需部署任何服务，开箱即用。

高可靠：背靠阿里云基础设施，SLA 有保障。

功能全面：支持多种任务类型、可观测、报警等。

生态集成：与阿里云其他服务（如消息、函数计算）无缝集成。

缺点：云厂商锁定，是付费服务。

总结：团队技术栈在阿里云上，且追求稳定和运维效率，预算充足时的最佳选择。

选型建议流程图
最终结论

无脑入门级选择：XXL-Job。它的生态、文档和易用性在开源中做到了最佳平衡，适用于绝大多数业务定时任务场景。

功能强大级选择：PowerJob。如果你的任务不仅仅是“定时触发”，还涉及到“怎么执行”（如工作流、MapReduce），它是更强大的现代化框架。

数据工作流核心选择：Apache DolphinScheduler。如果你的核心是调度数据任务、有复杂的DAG依赖关系，它就是为此而生。

企业上云/免运维选择：阿里云 SchedulerX​ 或其他云厂商的类似服务（如腾讯云的 TCT）。用金钱换取稳定性和 for

传统/嵌入式场景：Quartz。作为库嵌入到小型或传统项目中仍然是不错的选择。

建议在技术选型时，可以先用 XXL-Job​ 或 PowerJob​ 搭建一个快速 Demo，体验其控制台和 API 设计，再结合团队的技术栈和长期规划做出决定。

JobRunr 跟它们有什么区别

好的，这是一个非常好的问题！JobRunr​ 确实是一个独特的存在，它与前面提到的框架有着本质上的不同。我将从架构设计、实现原理和适用场景三个方面详细对比。

JobRunr 的核心特点

JobRunr 首先是一个分布式作业队列和后台作业处理器，其次才是一个调度器。它的设计哲学更接近异步任务处理，而传统框架更偏向定时任务调度。

适用场景决策树
如何选择？
选择 JobRunr 当：

需要处理大量异步任务（如发送邮件、消息推送、图片处理）

总结

JobRunr 与传统调度框架不是替代关系，而是互补关系：

JobRunr​ 更像是一个 "分布式异步任务处理器"，专注于事件驱动的后台作业

XXL-Job/PowerJob​ 更像是 "中央任务调度器"，专注于时间驱动的定时任务

如果你的应用有大量请求-响应后需要异步处理的场景，JobRunr 会让代码更简洁、更健壮。如果你主要是做定时批处理、数据同步、报表生成，传统调度框架更合适。

在现代化微服务架构中，很多团队会同时使用两者：用 JobRunr 处理服务内的异步任务，用 XXL-Job/PowerJob 处理跨服务的定时调度任务。

public class RecurringJobScheduler {
    public String scheduleRecurringly(String id, Runnable job, String cron) {
        // 关键：基于 id 的分布式锁
        if (acquireLock(id)) {      // 第一个获得锁的实例成为"执行者"
            persistJob(id, job, cron);
            return id;
        } else {                    // 其他实例成为"备份"
            return null;  // 任务已存在，不重复创建
        }
    }

为什么 JobRunr 非常适合这个场景？

方案1：周期性扫描 + 分布式锁（推荐）

@Service
@Slf4j
public class S3FileProcessor {

    @Autowired
    private S3Client s3Client;

    @Autowired
    private StorageProvider storageProvider;

    private final String bucketName = "my-bucket";
    private final String lockPrefix = "s3-file-lock:";

    /**
     * 单例任务：只有一个实例会执行扫描
     */
    @Recurring(
        id = "s3-file-scanner",
        cron = "*/30 * * * * *",  // 每30秒扫描一次
        description = "扫描S3新文件"
    )
    public void scanAndProcessNewFiles() {
        log.info("开始扫描S3新文件...");

        // 1. 列出S3中的新文件
        List<S3FileInfo> newFiles = listNewFiles();

        // 2. 为每个新文件创建处理任务
        for (S3FileInfo file : newFiles) {
            processFileAsync(file);
        }
    }

    /**
     * 异步处理单个文件
     * 通过唯一ID确保文件不被重复处理
     */
    private void processFileAsync(S3FileInfo file) {
        String jobId = "s3-process-" + file.getKey();

        // 关键：每个文件有唯一ID，JobRunr保证幂等性
        BackgroundJob.enqueue(
            jobId,  // 唯一任务ID，相同ID的任务不会重复执行
            () -> processSingleFile(file)
        );

        log.debug("已提交文件处理任务: {} (ID: {})", file.getKey(), jobId);
    }

    /**
     * 处理单个文件的具体逻辑
     */
    @Job(name = "处理S3文件: %0", retries = 3)
    public void processSingleFile(S3FileInfo file) {
        String fileKey = file.getKey();
        log.info("开始处理文件: {}", fileKey);

        try {
            // 1. 再次检查是否已被处理（双重校验）
            if (isFileProcessed(fileKey)) {
                log.info("文件已被处理，跳过: {}", fileKey);
                return;
            }

            // 2. 获取文件内容
            byte[] content = s3Client.getObjectBytes(bucketName, fileKey);

            // 3. 业务处理逻辑
            processContent(fileKey, content);

            // 4. 标记为已处理
            markFileAsProcessed(fileKey);

            log.info("文件处理完成: {}", fileKey);

        } catch (Exception e) {
            log.error("处理文件失败: {}", fileKey, e);
            throw e; // 抛出异常会触发JobRunr的重试机制
        }
    }

    /**
     * 列出需要处理的新文件
     */
    private List<S3FileInfo> listNewFiles() {
        ListObjectsV2Request request = ListObjectsV2Request.builder()
            .bucket(bucketName)
            .prefix("uploads/")  // 只扫描特定目录
            .build();

        return s3Client.listObjectsV2(request).contents().stream()
            .filter(this::isNewFile)  // 过滤新文件
            .filter(this::isValidType) // 过滤文件类型
            .map(this::toFileInfo)
            .collect(Collectors.toList());
    }

    /**
     * 判断是否是新文件
     */
    private boolean isNewFile(S3Object s3Object) {
        // 根据最后修改时间判断（例如：最近1小时内的文件）
        Instant oneHourAgo = Instant.now().minus(1, ChronoUnit.HOURS);
        return s3Object.lastModified().isAfter(oneHourAgo);
    }

    /**
     * 检查文件是否已被处理
     */
    private boolean isFileProcessed(String fileKey) {
        // 使用Redis或数据库记录已处理文件
        // 这里用JobRunr的StorageProvider作为示例
        String lockKey = lockPrefix + fileKey;
        return storageProvider.getRecurringJobById(lockKey) != null;
    }

    /**
     * 标记文件为已处理
     */
    private void markFileAsProcessed(String fileKey) {
        String lockKey = lockPrefix + fileKey;
        // 可以存储到Redis、数据库或使用JobRunr的metadata
        storageProvider.saveMetadata(lockKey, "processed", Instant.now().toString());
    }
}

@Component
@Slf4j
public class AdvancedS3Processor {

    @Value("${s3.bucket-name}")
    private String bucketName;

    @Value("${s3.scan.cron:0 */5 * * * *}")
    private String scanCron;

    @Autowired
    private S3Service s3Service;

    @Autowired
    private FileProcessor fileProcessor;

    @Autowired
    private JobRunrMetadataService metadataService;

    /**
     * 主扫描任务 - 单例运行
     */
    @Recurring(id = "s3-main-scanner", cron = "${s3.scan.cron}")
    @Job(name = "S3主扫描器")
    public void mainScanner() {
        log.info("=== S3扫描开始 ===");

        // 分页扫描，避免内存溢出
        String continuationToken = null;
        int processedCount = 0;

        do {
            ScanResult scanResult = s3Service.scanNewFiles(
                bucketName,
                continuationToken
            );

            // 异步处理每个文件
            scanResult.getFiles().forEach(this::scheduleFileProcessing);

            processedCount += scanResult.getFiles().size();
            continuationToken = scanResult.getContinuationToken();

        } while (continuationToken != null && processedCount < 1000); // 限制每次扫描数量

        log.info("=== S3扫描完成，发现{}个新文件 ===", processedCount);
    }

    /**
     * 调度文件处理 - 确保幂等性
     */
    private void scheduleFileProcessing(S3FileInfo file) {
        String fileId = generateFileId(file);

        // 方法1: 使用JobRunr内置的幂等性
        String jobId = "process-s3-file-" + fileId;

        // 检查是否已有处理任务
        if (metadataService.jobExists(jobId)) {
            log.debug("文件处理任务已存在: {}", file.getKey());
            return;
        }

        // 方法2: 使用分布式锁
        DistributedLock lock = acquireFileLock(fileId);
        if (!lock.tryLock()) {
            log.debug("文件正在被其他实例处理: {}", file.getKey());
            return;
        }

        try {
            // 提交处理任务
            BackgroundJob.<AdvancedS3Processor>enqueue(
                x -> x.processFileWithRetry(file)
            );

            log.info("已调度文件处理: {}", file.getKey());

        } finally {
            lock.unlock();
        }
    }

    /**
     * 处理文件（带重试策略）
     */
    @Job(
        name = "处理文件: %0.key",
        retries = 3,
        retryBackOff = @RetryBackOff(delay = 1000, maxDelay = 10000)
    )
    public void processFileWithRetry(S3FileInfo file) {
        log.info("开始处理文件: {}", file.getKey());

        try {
            // 下载文件
            byte[] content = s3Service.downloadFile(file.getBucket(), file.getKey());

            // 验证文件（防止处理到一半的文件）
            if (!isFileComplete(file, content)) {
                log.warn("文件不完整，稍后重试: {}", file.getKey());
                throw new FileIncompleteException(file.getKey());
            }

            // 业务处理
            ProcessResult result = fileProcessor.process(file.getKey(), content);

            // 记录处理结果
            saveProcessingResult(file, result);

            // 可选：移动或删除已处理的文件
            if (result.isSuccess()) {
                s3Service.moveToProcessed(file);
            }

            log.info("文件处理成功: {}", file.getKey());

        } catch (Exception e) {
            log.error("文件处理失败: {}", file.getKey(), e);

            // 根据异常类型决定是否重试
            if (shouldRetry(e)) {
                throw e; // JobRunr会自动重试
            } else {
                // 不可恢复的错误，标记为失败
                markAsFailed(file, e);
            }
        }
    }

    /**
     * 生成唯一文件ID
     */
    private String generateFileId(S3FileInfo file) {
        // 使用文件路径+大小+最后修改时间
        return String.format("%s-%d-%d",
            file.getKey(),
            file.getSize(),
            file.getLastModified().toEpochMilli()
        );
    }

    /**
     * 检查文件是否完整
     */
    private boolean isFileComplete(S3FileInfo file, byte[] content) {
        // 检查文件大小是否匹配
        if (content.length != file.getSize()) {
            return false;
        }

        // 检查文件扩展名/格式
        if (file.getKey().endsWith(".tmp") || file.getKey().endsWith(".part")) {
            return false;
        }

        // 可以添加更多的完整性检查
        return true;
    }
}

@Service
@Slf4j
public class S3FileRetryHandler {

    @Autowired
    private S3Client s3Client;

    @Autowired
    private JobRunrStorage storage;

    /**
     * 触发单个文件的重新处理
     */
    public void retryFailedFile(String fileName, RetryConfig config) {
        // 生成唯一的任务ID，避免重复重试
        String jobId = "retry-" + fileName + "-" + System.currentTimeMillis();

        // 动态传参创建任务
        BackgroundJobRequest request = BackgroundJobRequestBuilder
            .aBackgroundJobRequest()
            .withId(jobId)  // 唯一ID
            .withName("重试处理文件: " + fileName)
            .withDetails(() ->
                reprocessFailedFile(
                    fileName,
                    config.getSourcePrefix(),
                    config.getTargetPrefix(),
                    config.getRetryCount() + 1
                )
            )
            .withRetryBackOffPolicy(RetryBackOffPolicy.exponentialBackoff(
                Duration.ofSeconds(10),
                Duration.ofMinutes(5)
            ))
            .scheduleAt(Instant.now().plus(config.getDelay(), ChronoUnit.SECONDS));

        log.info("已创建文件重试任务: {}, 文件名: {}", jobId, fileName);
    }

    /**
     * 重新处理失败的文件
     */
    @Job(name = "重新处理文件: %0", retries = 3)
    public void reprocessFailedFile(
            String fileName,
            String sourcePrefix,  // 如: "failed/"
            String targetPrefix,  // 如: "processed/" 或 "archived/"
            int retryCount) {

        log.info("开始第{}次重试处理文件: {}/{}",
            retryCount, sourcePrefix, fileName);

        try {
            // 1. 从失败目录读取文件
            String sourceKey = sourcePrefix + fileName;
            byte[] content = s3Client.getObjectBytes("my-bucket", sourceKey);

            // 2. 执行业务处理
            ProcessResult result = processFileContent(fileName, content);

            if (result.isSuccess()) {
                // 3. 处理成功，移动到目标目录
                String targetKey = targetPrefix + fileName;
                s3Client.copyObject(copyReq -> copyReq
                    .sourceBucket("my-bucket").sourceKey(sourceKey)
                    .destinationBucket("my-bucket").destinationKey(targetKey)
                );

                // 4. 删除原文件
                s3Client.deleteObject(deleteReq -> deleteReq
                    .bucket("my-bucket")
                    .key(sourceKey)
                );

                log.info("文件重试成功: {}, 已移动到: {}", fileName, targetPrefix);

                // 5. 发送成功通知
                sendSuccessNotification(fileName, retryCount);

            } else {
                throw new FileProcessingException("文件处理失败: " + result.getError());
            }

        } catch (Exception e) {
            log.error("文件重试失败: {}", fileName, e);

            // 记录失败信息
            recordRetryFailure(fileName, retryCount, e.getMessage());

            // 如果达到最大重试次数，移动到死信目录
            if (retryCount >= 3) {
                moveToDeadLetter(fileName, sourcePrefix);
            }

            throw e; // JobRunr会自动重试
        }
    }

    /**
     * 批量重试失败文件
     */
    public void batchRetryFailedFiles(List<String> fileNames, RetryConfig config) {
        for (String fileName : fileNames) {
            retryFailedFile(fileName, config);
        }
    }

    /**
     * 根据条件重试文件
     */
    public void retryFilesByCondition(RetryCondition condition) {
        // 查询符合条件的失败文件
        List<FailedFileInfo> failedFiles = findFailedFiles(condition);

        failedFiles.forEach(file -> {
            RetryConfig config = RetryConfig.builder()
                .sourcePrefix("failed/")
                .targetPrefix("processed/")
                .delay(file.getRetryCount() * 60L)  // 重试次数越多，延迟越长
                .retryCount(file.getRetryCount())
                .build();

            retryFailedFile(file.getFileName(), config);
        });
    }
}

@RestController
@RequestMapping("/api/files")
@Slf4j
public class FileRetryController {

    @Autowired
    private S3FileRetryHandler retryHandler;

    @Autowired
    private StorageProvider jobStorage;

    /**
     * 重试单个失败文件
     */
    @PostMapping("/{fileName}/retry")
    public ResponseEntity<?> retryFile(
            @PathVariable String fileName,
            @RequestBody RetryRequest request) {

        log.info("收到文件重试请求: {}, 参数: {}", fileName, request);

        // 检查文件是否存在
        if (!fileExists(request.getSourcePrefix(), fileName)) {
            return ResponseEntity.notFound().build();
        }

        // 检查是否已有重试任务
        if (hasPendingRetryJob(fileName)) {
            return ResponseEntity.status(HttpStatus.CONFLICT)
                .body("该文件已有待处理的重试任务");
        }

        // 创建重试任务
        String jobId = retryHandler.retryFailedFile(fileName, request.toConfig());

        return ResponseEntity.accepted()
            .header("X-Job-Id", jobId)
            .body(Map.of(
                "jobId", jobId,
                "fileName", fileName,
                "status", "pending",
                "message", "重试任务已创建"
            ));
    }

    /**
     * 批量重试
     */
    @PostMapping("/batch-retry")
    public ResponseEntity<?> batchRetry(@RequestBody BatchRetryRequest request) {
        List<RetryResult> results = new ArrayList<>();

        for (String fileName : request.getFileNames()) {
            try {
                String jobId = retryHandler.retryFailedFile(
                    fileName,
                    request.getRetryConfig()
                );

                results.add(RetryResult.success(fileName, jobId));

            } catch (Exception e) {
                results.add(RetryResult.failed(fileName, e.getMessage()));
            }
        }

        return ResponseEntity.ok(results);
    }

    /**
     * 根据条件重试
     */
    @PostMapping("/retry-by-condition")
    public ResponseEntity<?> retryByCondition(@RequestBody RetryCondition condition) {

        int retryCount = retryHandler.retryFilesByCondition(condition);

        return ResponseEntity.ok(Map.of(
            "message", "已创建 " + retryCount + " 个重试任务",
            "condition", condition.toString()
        ));
    }

    /**
     * 取消重试任务
     */
    @DeleteMapping("/retry/{jobId}")
    public ResponseEntity<?> cancelRetry(@PathVariable String jobId) {
        Job job = jobStorage.getJobById(jobId);

        if (job == null) {
            return ResponseEntity.notFound().build();
        }

        if (job.getState() == JobState.SCHEDULED || job.getState() == JobState.ENQUEUED) {
            job.delete("手动取消");
            return ResponseEntity.ok("重试任务已取消");
        } else {
            return ResponseEntity.badRequest()
                .body("任务已开始执行，无法取消");
        }
    }

    /**
     * 获取文件的重试历史
     */
    @GetMapping("/{fileName}/retry-history")
    public ResponseEntity<?> getRetryHistory(@PathVariable String fileName) {
        List<Job> retryJobs = jobStorage.findJobs(
            JobDetailsQuery.selectJobs()
                .whereNameContains(fileName)
                .withStates(JobState.SUCCEEDED, JobState.FAILED)
        );

        List<RetryHistory> history = retryJobs.stream()
            .map(this::toRetryHistory)
            .collect(Collectors.toList());

        return ResponseEntity.ok(history);
    }
}

@Component
@Slf4j
public class FileRetryEventHandler {

    @Autowired
    private S3FileRetryHandler retryHandler;

    /**
     * 监听文件处理失败事件
     */
    @EventListener
    public void handleFileProcessingFailed(FileProcessingFailedEvent event) {
        log.warn("文件处理失败，准备重试: {}", event.getFileName());

        // 动态创建重试任务
        RetryConfig config = RetryConfig.builder()
            .sourcePrefix(event.getSourcePath())
            .targetPrefix("retry-attempt-" + event.getAttemptCount() + "/")
            .delay(calculateRetryDelay(event.getAttemptCount()))
            .retryCount(event.getAttemptCount())
            .build();

        String jobId = retryHandler.retryFailedFile(
            event.getFileName(),
            config
        );

        // 发布任务创建事件
        applicationEventPublisher.publishEvent(
            new RetryJobCreatedEvent(jobId, event)
        );
    }

    /**
     * 监听管理指令
     */
    @EventListener
    public void handleAdminCommand(AdminRetryCommand command) {
        switch (command.getType()) {
            case RETRY_ALL_FAILED:
                retryHandler.retryFilesByCondition(
                    RetryCondition.failedInLastHours(24)
                );
                break;

            case RETRY_BY_PATTERN:
                retryHandler.retryFilesByCondition(
                    RetryCondition.fileNameLike(command.getPattern())
                );
                break;

            case RETRY_SPECIFIC:
                command.getFileNames().forEach(fileName ->
                    retryHandler.retryFailedFile(fileName, command.getConfig())
                );
                break;
        }
    }
}

        );
    }

    /**
     * 手动触发重试
     */

    public ResponseEntity<?> retryJob(@PathVariable String jobId) {
        Job job = storageProvider.getJobById(jobId);

        if (job == null) {
            return ResponseEntity.notFound().build();
        }

        if (job.getState() == JobState.FAILED) {
            // 重新入队
            job.enqueue();
            return ResponseEntity.ok("任务已重新加入队列");
        }

        return ResponseEntity.badRequest()
            .body("只有失败的任务才能重试");
    }

@Component
public class SmartFileRetryService {

    /**
     * 智能重试 - 根据失败原因使用不同策略
     */
    public void smartRetry(String fileName, String failureReason) {
        RetryStrategy strategy = determineRetryStrategy(failureReason);

        BackgroundJobRequest request = BackgroundJobRequestBuilder
            .aBackgroundJobRequest()
            .withId("smart-retry-" + fileName)
            .withDetails(() -> processWithStrategy(fileName, strategy))
            .withRetryBackOffPolicy(strategy.getBackOffPolicy())
            .withAmountOfRetries(strategy.getMaxRetries())
            .scheduleAt(calculateScheduleTime(strategy));

        log.info("使用策略 {} 重试文件: {}", strategy.getName(), fileName);
    }

    /**
     * 带条件的重试
     */
    public void conditionalRetry(String fileName, RetryCondition condition) {
        BackgroundJobRequest request = BackgroundJobRequestBuilder
            .aBackgroundJobRequest()
            .withId("conditional-retry-" + fileName)
            .withDetails(() -> {
                // 检查条件是否仍然满足
                if (condition.isSatisfied(fileName)) {
                    reprocessFile(fileName);
                } else {
                    log.info("条件不满足，跳过重试: {}", fileName);
                }
            })
            .scheduleAt(Instant.now().plus(5, ChronoUnit.MINUTES));
    }

    /**
     * 链式重试
     */
    public void chainedRetry(String fileName) {
        // 第一步：验证文件
        String validateJobId = BackgroundJobRequestBuilder
            .aBackgroundJobRequest()
            .withName("验证文件: " + fileName)
            .withDetails(() -> validateFile(fileName))
            .enqueue();

        // 第二步：处理文件（第一步成功后执行）
        BackgroundJobRequestBuilder
            .aBackgroundJobRequest()
            .withName("处理文件: " + fileName)
            .withDetails(() -> processFile(fileName))
            .after(validateJobId)  // 在验证成功后执行
            .enqueue();

        // 第三步：清理（无论成功失败都执行）
        BackgroundJobRequestBuilder
            .aBackgroundJobRequest()
            .withName("清理: " + fileName)
            .withDetails(() -> cleanup(fileName))
            .enqueue();
    }
}

@RestController
@RequestMapping("/api/jobrunr/jobs")
@Slf4j
public class JobRunrJobCreatorController {

    @Autowired
    private JobRunrStorageProvider jobStorage;

    @Autowired
    private ApplicationContext applicationContext;

    /**
     * 创建处理文件的任务
     */
    @PostMapping("/create-file-job")
    public ResponseEntity<Map<String, Object>> createFileJob(
            @RequestBody CreateFileJobRequest request) {

        try {
            // 方法1：使用反射调用（更灵活）
            String jobId = createJobViaReflection(request);

            // 方法2：或使用预定义的服务方法
            // String jobId = createJobViaService(request);

            return ResponseEntity.ok(Map.of(
                "success", true,
                "jobId", jobId,
                "message", "任务创建成功",
                "dashboardUrl", "/jobrunr/dashboard/jobs/" + jobId
            ));

        } catch (Exception e) {
            return ResponseEntity.badRequest()
                .body(Map.of(
                    "success", false,
                    "error", e.getMessage()
                ));
        }
    }

    private String createJobViaReflection(CreateFileJobRequest request) {
        // 构建任务详情
        JobDetails jobDetails = new JobDetails(
            request.getBeanName(),  // Spring bean 名称
            request.getMethodName(), // 方法名
            request.getArgs()        // 参数数组
        );

        // 创建任务
        Job job = new Job(jobDetails);
        job.setJobName(request.getJobName());

        // 设置重试策略
        if (request.getRetryPolicy() != null) {
            job.setAmountOfRetries(request.getRetryPolicy().getMaxRetries());
        }

        // 保存任务
        jobStorage.save(job);

        // 立即执行或延迟执行
        if (request.getScheduleAt() != null) {
            job.scheduleAt(request.getScheduleAt());
        } else {
            job.enqueue();
        }

        return job.getId().toString();
    }

    /**
     * 通过 JobRunr 的 HTTP API 创建任务
     */
    @PostMapping("/create-via-http")
    public String createJobViaHttp(@RequestBody JobCreationRequest request) {
        // JobRunr 6.0+ 提供了 HTTP API
        // 可以从前端直接调用

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);

        Map<String, Object> jobRequest = Map.of(
            "type", "job",
            "jobDetails", Map.of(
                "className", request.getClassName(),
                "methodName", request.getMethodName(),
                "args", request.getArgs()
            ),
            "jobName", request.getJobName(),
            "labels", request.getLabels()
        );

        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(jobRequest, headers);

        RestTemplate restTemplate = new RestTemplate();
        ResponseEntity<String> response = restTemplate.postForEntity(
            "http://localhost:8000/api/jobs",
            entity,
            String.class
        );

        return response.getBody();
    }
}

@Component
@ConditionalOnProperty(name = "jobrunr.dashboard.enabled", havingValue = "true")
public class DashboardLeaderElection {

    @Value("${server.port:8080}")
    private int serverPort;

    @Autowired
    private RedisLockRegistry lockRegistry;

    @PostConstruct
    public void electDashboardLeader() {
        Lock lock = lockRegistry.obtain("jobrunr-dashboard-leader");

        if (lock.tryLock()) {
            // 获得锁，成为Dashboard节点
            log.info("当前实例被选为JobRunr Dashboard节点，端口: {}", serverPort);
            enableDashboard();
        } else {
            // 未获得锁，禁用Dashboard
            log.info("当前实例作为Worker节点运行");
            disableDashboard();
        }
    }

    private void enableDashboard() {
        JobRunr.configure()
            .useDashboard(serverPort + 1, "/dashboard")  // Dashboard在 serverPort+1
            .initialize();
    }

    private void disableDashboard() {
        JobRunr.configure()
            .useDashboard(null)  // 禁用Dashboard
            .initialize();
    }
}

@Configuration
@ConditionalOnClass(JobRunr.class)
public class SmartDashboardAutoConfiguration {

    @Value("${jobrunr.dashboard.auto-elect:true}")
    private boolean autoElect;

    @Autowired
    private Environment environment;

    @Bean
    @ConditionalOnMissingBean
    public JobRunrConfiguration jobRunrConfiguration(DataSource dataSource) {
        JobRunrConfiguration config = JobRunr.configure()
            .useStorageProvider(SqlStorageProviderFactory.using(dataSource))
            .useBackgroundJobServer();

        // 智能判断是否启用Dashboard
        if (shouldEnableDashboard()) {
            int dashboardPort = getAvailableDashboardPort();
            config.useDashboard(dashboardPort);
            log.info("启用JobRunr Dashboard，端口: {}", dashboardPort);
        } else {
            log.info("当前实例不启用JobRunr Dashboard");
        }

        return config;
    }

    private boolean shouldEnableDashboard() {
        // 1. 检查显式配置
        if (environment.containsProperty("jobrunr.dashboard.enabled")) {
            return environment.getProperty("jobrunr.dashboard.enabled", Boolean.class, false);
        }

        // 2. 自动选举逻辑
        if (autoElect) {
            return isElectedAsDashboardNode();
        }

        return false;
    }

    private boolean isElectedAsDashboardNode() {
        try {
            // 方法1: 基于主机名/IP的稳定选举
            String hostname = InetAddress.getLocalHost().getHostName();
            String[] instances = getClusterInstances(); // 从注册中心获取

            // 选择第一个实例（按字母排序）
            Arrays.sort(instances);
            return hostname.equals(instances[0]);

        } catch (Exception e) {
            log.warn("Dashboard选举失败，禁用Dashboard", e);
            return false;
        }
    }

    private int getAvailableDashboardPort() {
        int basePort = environment.getProperty("jobrunr.dashboard.port", Integer.class, 8000);

        // 如果端口被占用，尝试相邻端口
        for (int i = 0; i < 10; i++) {
            int port = basePort + i;
            if (isPortAvailable(port)) {
                return port;
            }
        }

        throw new IllegalStateException("找不到可用的Dashboard端口");
    }
}

@Configuration
@ConditionalOnCloudPlatform(CloudPlatform.KUBERNETES)
public class CloudNativeDashboardConfig {

    @Autowired
    private DiscoveryClient discoveryClient;

    @Bean
    public SmartDashboardEnabler dashboardEnabler() {
        return new SmartDashboardEnabler(discoveryClient);
    }

    @RequiredArgsConstructor
    public static class SmartDashboardEnabler
            implements ApplicationRunner, ApplicationListener<WebServerInitializedEvent> {

        private final DiscoveryClient discoveryClient;
        private volatile boolean isDashboardNode = false;
        private int dashboardPort = 8000;

        @Override
        public void run(ApplicationArguments args) throws Exception {
            // 应用启动时选举Dashboard节点
            electDashboardNode();
        }

        private void electDashboardNode() {
            // 获取所有应用实例
            List<ServiceInstance> instances = discoveryClient.getInstances("my-application");

            if (instances.isEmpty()) {
                // 单实例模式，启用Dashboard
                isDashboardNode = true;
                return;
            }

            // 按实例ID排序，选择第一个
            instances.sort(Comparator.comparing(ServiceInstance::getInstanceId));

            String currentInstanceId = getCurrentInstanceId();
            String electedInstanceId = instances.get(0).getInstanceId();

            isDashboardNode = currentInstanceId.equals(electedInstanceId);

            log.info("Dashboard选举结果: 当前实例{}，当选实例{}，当前节点{}Dashboard",
                currentInstanceId, electedInstanceId,
                isDashboardNode ? "是" : "不是");
        }

        @Override
        public void onApplicationEvent(WebServerInitializedEvent event) {
            if (isDashboardNode) {
                // 启用JobRunr Dashboard
                enableJobRunrDashboard(event.getWebServer().getPort());
            }
        }

        private void enableJobRunrDashboard(int appPort) {
            JobRunr.configure()

@Component
public class SmartDashboardRouter {

    @GetMapping("/dashboard")
    public void redirectToActiveDashboard(HttpServletResponse response) {
        // 1. 检测哪个实例是"主"Dashboard
        String activeDashboardUrl = findActiveDashboard();

        // 2. 如果当前实例是主Dashboard，直接服务
        if (isActiveDashboard()) {
            // 返回Dashboard页面
            return;
        }

        // 3. 否则重定向到主Dashboard
        response.sendRedirect(activeDashboardUrl);
    }

    private String findActiveDashboard() {
        // 方法1: 基于配置
        if (environment.containsProperty("dashboard.primary.url")) {
            return environment.getProperty("dashboard.primary.url");
        }

        // 方法2: 服务发现选举
        List<ServiceInstance> instances = discoveryClient.getInstances("my-app");
        instances.sort(Comparator.comparing(ServiceInstance::getInstanceId));
        ServiceInstance primary = instances.get(0);

        return "http://" + primary.getHost() + ":" +
               (primary.getPort() + 1000);  // Dashboard端口约定
    }

    private boolean isActiveDashboard() {
        String currentInstance = getCurrentInstanceId();
        String activeInstance = getActiveDashboardInstanceId();
        return currentInstance.equals(activeInstance);
    }
}

7. 高级方案：Dashboard 集群模式

下载

@Component
public class DashboardClusterManager {

    private final String clusterId = "jobrunr-dashboard-cluster";
    private final String instanceId = UUID.randomUUID().toString();

    @PostConstruct
    public void joinCluster() {
        // 注册到Dashboard集群
        redisTemplate.opsForZSet().add(
            clusterId,
            instanceId,
            System.currentTimeMillis()
        );

        // 设置过期，自动清理宕机节点
        redisTemplate.expire(clusterId, 30, TimeUnit.SECONDS);

        // 选举主节点
        electLeader();
    }

    private void electLeader() {
        Set<String> instances = redisTemplate.opsForZSet()
            .range(clusterId, 0, 0);  // 最老的实例

        if (!instances.isEmpty() && instances.iterator().next().equals(instanceId)) {
            // 当前实例是主节点
            enableFullDashboard();
        } else {
            // 当前实例是从节点
            enableReadOnlyDashboard();
        }
    }

    private void enableFullDashboard() {
        // 启用完整Dashboard功能
        JobRunr.configure()
            .useDashboard(8000, true)  // 启用WebSocket
            .initialize();
    }

    private void enableReadOnlyDashboard() {
        // 启用只读Dashboard
        JobRunr.configure()
            .useDashboard(8000, false)  // 禁用WebSocket
            .initialize();
    }
}

@Service
@Slf4j
public class DashboardElectorService {

    private static final String LOCK_TABLE = "jobrunr_dashboard_lock";
    private static final long LOCK_TTL_MS = 30000; // 30秒租约
    private static final long HEARTBEAT_INTERVAL_MS = 10000; // 10秒心跳

    @Autowired
    private JdbcTemplate jdbcTemplate;

    private final String instanceId = generateInstanceId();
    private volatile boolean isLeader = false;
    private volatile long leaseExpiry = 0;
    private ScheduledExecutorService heartbeatScheduler;

    @PostConstruct
    public void init() {
        createLockTableIfNotExists();
        startElection();
        startHeartbeat();
    }

    @PreDestroy
    public void cleanup() {
        if (heartbeatScheduler != null) {
            heartbeatScheduler.shutdown();
        }
        if (isLeader) {
            releaseLeadership();
        }
    }

    /**
     * 创建分布式锁表
     */
    private void createLockTableIfNotExists() {
        String sql = """
            CREATE TABLE IF NOT EXISTS %s (
                lock_key VARCHAR(100) PRIMARY KEY,
                instance_id VARCHAR(100) NOT NULL,
                lease_expiry BIGINT NOT NULL,
                last_heartbeat BIGINT NOT NULL,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
            """.formatted(LOCK_TABLE);

        jdbcTemplate.execute(sql);
        log.info("分布式锁表已创建/验证: {}", LOCK_TABLE);
    }

    /**
     * 开始选举
     */
    private void startElection() {
        log.info("实例 {} 开始参与Dashboard主节点选举", instanceId);

        // 尝试获取锁
        boolean acquired = tryAcquireLock();

        if (acquired) {
            isLeader = true;
            leaseExpiry = System.currentTimeMillis() + LOCK_TTL_MS;
            log.info("🎉 实例 {} 当选为Dashboard主节点，租约到期: {}",
                instanceId, new Date(leaseExpiry));

            // 启用完整Dashboard功能
            enableFullDashboard();
        } else {
            log.info("实例 {} 作为备用节点运行", instanceId);

            // 启用只读Dashboard
            enableReadOnlyDashboard();
        }
    }

    /**
     * 尝试获取分布式锁
     */
    private boolean tryAcquireLock() {
        long now = System.currentTimeMillis();

        try {
            // 方法1: 使用数据库CAS操作
            String acquireSql = """
                INSERT INTO %s (lock_key, instance_id, lease_expiry, last_heartbeat)
                VALUES ('dashboard_leader', ?, ?, ?)
                ON DUPLICATE KEY UPDATE
                    instance_id = IF(lease_expiry < ?, VALUES(instance_id), instance_id),
                    lease_expiry = IF(lease_expiry < ?, VALUES(lease_expiry), lease_expiry),
                    last_heartbeat = IF(lease_expiry < ?, VALUES(last_heartbeat), last_heartbeat)
                """.formatted(LOCK_TABLE);

            int updated = jdbcTemplate.update(acquireSql,
                instanceId, now + LOCK_TTL_MS, now,
                now, // 如果锁已过期，可以抢占
                now,
                now
            );

            // 检查当前持有者是否是自己
            String checkSql = "SELECT instance_id FROM %s WHERE lock_key = 'dashboard_leader'"
                .formatted(LOCK_TABLE);
            String currentHolder = jdbcTemplate.queryForObject(checkSql, String.class);

            return instanceId.equals(currentHolder);

        } catch (Exception e) {
            log.error("获取锁失败", e);
            return false;
        }
    }

    /**
     * 心跳续租
     */
    private void startHeartbeat() {
        heartbeatScheduler = Executors.newSingleThreadScheduledExecutor(r -> {
            Thread t = new Thread(r, "dashboard-heartbeat");
            t.setDaemon(true);
            return t;
        });

        heartbeatScheduler.scheduleAtFixedRate(() -> {
            try {
                if (isLeader) {
                    renewLease();
                } else {
                    // 备用节点检查主节点是否存活
                    checkLeaderStatus();
                }
            } catch (Exception e) {
                log.error("心跳处理异常", e);
            }
        }, HEARTBEAT_INTERVAL_MS, HEARTBEAT_INTERVAL_MS, TimeUnit.MILLISECONDS);
    }

    /**
     * 续租
     */
    private void renewLease() {
        long now = System.currentTimeMillis();

        if (now >= leaseExpiry - 5000) { // 提前5秒续租
            String renewSql = """
                UPDATE %s
                SET lease_expiry = ?, last_heartbeat = ?
                WHERE lock_key = 'dashboard_leader' AND instance_id = ?
                """.formatted(LOCK_TABLE);

            int updated = jdbcTemplate.update(renewSql,
                now + LOCK_TTL_MS, now, instanceId);

            if (updated > 0) {
                leaseExpiry = now + LOCK_TTL_MS;
                log.debug("主节点续租成功，新租约到期: {}", new Date(leaseExpiry));
            } else {
                // 续租失败，失去领导权
                log.warn("主节点续租失败，可能已被其他节点抢占");
                isLeader = false;
                enableReadOnlyDashboard();
                // 重新参与选举
                startElection();
            }
        }
    }

    /**
     * 检查主节点状态
     */
    private void checkLeaderStatus() {
        String sql = """
            SELECT instance_id, lease_expiry
            FROM %s
            WHERE lock_key = 'dashboard_leader'
            """.formatted(LOCK_TABLE);

        try {
            Map<String, Object> result = jdbcTemplate.queryForMap(sql);
            String leaderId = (String) result.get("instance_id");
            long expiry = ((Number) result.get("lease_expiry")).longValue();

            long now = System.currentTimeMillis();

            if (now > expiry) {
                // 主节点租约已过期，尝试抢占
                log.warn("主节点 {} 租约已过期，尝试抢占", leaderId);
                boolean acquired = tryAcquireLock();

                if (acquired) {
                    isLeader = true;
                    leaseExpiry = now + LOCK_TTL_MS;
                    log.info("🚀 实例 {} 抢占成为新的主节点", instanceId);
                    enableFullDashboard();
                }
            }
        } catch (EmptyResultDataAccessException e) {
            // 没有主节点，尝试成为主节点
            log.info("没有发现主节点，尝试成为主节点");
            boolean acquired = tryAcquireLock();
            if (acquired) {
                isLeader = true;
                leaseExpiry = System.currentTimeMillis() + LOCK_TTL_MS;
                log.info("🚀 实例 {} 成为新的主节点", instanceId);
                enableFullDashboard();
            }
        }
    }

    /**
     * 释放领导权
     */
    private void releaseLeadership() {
        String sql = "DELETE FROM %s WHERE lock_key = 'dashboard_leader' AND instance_id = ?"
            .formatted(LOCK_TABLE);

        jdbcTemplate.update(sql, instanceId);
        log.info("实例 {} 释放主节点身份", instanceId);
    }

    /**
     * 启用完整Dashboard
     */
    private void enableFullDashboard() {
        // 设置WebSocket启用标志
        System.setProperty("jobrunr.dashboard.websocket.enabled", "true");
        log.info("启用完整Dashboard功能（WebSocket已启用）");
    }

    /**
     * 启用只读Dashboard
     */
    private void enableReadOnlyDashboard() {
        // 设置WebSocket禁用标志
        System.setProperty("jobrunr.dashboard.websocket.enabled", "false");
        log.info("启用只读Dashboard功能（WebSocket已禁用）");
    }

    /**
     * 生成实例ID
     */
    private String generateInstanceId() {
        try {
            String hostname = InetAddress.getLocalHost().getHostName();
            return hostname + "-" + ManagementFactory.getRuntimeMXBean().getName().split("@")[0];
        } catch (Exception e) {
            return UUID.randomUUID().toString();
        }
    }

    /**
     * 公开接口：检查是否是主节点
     */
    public boolean isLeader() {
        return isLeader;
    }

    /**
     * 公开接口：获取主节点信息
     */
    public LeaderInfo getLeaderInfo() {
        String sql = "SELECT instance_id, lease_expiry FROM %s WHERE lock_key = 'dashboard_leader'"
            .formatted(LOCK_TABLE);

        try {
            Map<String, Object> result = jdbcTemplate.queryForMap(sql);
            return new LeaderInfo(
                (String) result.get("instance_id"),
                ((Number) result.get("lease_expiry")).longValue()
            );
        } catch (EmptyResultDataAccessException e) {
            return null;
        }
    }

    @Data
    @AllArgsConstructor
    public static class LeaderInfo {
        private String instanceId;
        private long leaseExpiry;
    }
}

@Component
@Slf4j
public class DashboardRoutingFilter extends OncePerRequestFilter {

    private final DashboardElectorService electorService;

    public DashboardRoutingFilter(DashboardElectorService electorService) {
        this.electorService = electorService;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                   HttpServletResponse response,
                                   FilterChain filterChain)
        throws ServletException, IOException {

        String requestURI = request.getRequestURI();

        // 1. 健康检查接口直接通过
        if (requestURI.contains("/dashboard/health") ||
            requestURI.contains("/dashboard/api/health")) {
            filterChain.doFilter(request, response);
            return;
        }

        // 2. 如果是WebSocket连接
        if (isWebSocketRequest(request)) {
            if (!electorService.isLeader()) {
                // 非主节点拒绝WebSocket连接
                response.sendError(HttpStatus.SERVICE_UNAVAILABLE.value(),
                    "WebSocket only available on leader node");
                return;
            }
        }

        // 3. 如果是API请求，检查是否是主节点
        else if (requestURI.contains("/dashboard/api/") &&
                 !requestURI.contains("/api/health")) {

            if (!electorService.isLeader()) {
                // 非主节点，重定向到主节点（如果需要）
                DashboardElectorService.LeaderInfo leader = electorService.getLeaderInfo();
                if (leader != null && shouldRedirectToLeader(request)) {
                    String leaderUrl = getLeaderDashboardUrl();
                    if (leaderUrl != null && !leaderUrl.isEmpty()) {
                        response.sendRedirect(leaderUrl + requestURI);
                        return;
                    }
                }
            }
        }

        // 4. 其他请求（静态资源等）都允许
        filterChain.doFilter(request, response);
    }

    private boolean isWebSocketRequest(HttpServletRequest request) {
        String upgrade = request.getHeader("Upgrade");
        return "websocket".equalsIgnoreCase(upgrade);
    }

    private boolean shouldRedirectToLeader(HttpServletRequest request) {
        // 只对写操作重定向
        String method = request.getMethod();
        return "POST".equals(method) || "PUT".equals(method) ||
               "DELETE".equals(method) || "PATCH".equals(method);
    }

    private String getLeaderDashboardUrl() {
        // 这里需要实现获取主节点URL的逻辑
        // 可以通过配置、服务发现或约定规则
        return System.getProperty("dashboard.leader.url", "");
    }
}

@Configuration
@Slf4j
public class SimpleDashboardConfig {

    @Value("${jobrunr.dashboard.port:8000}")
    private int dashboardPort;

    @Bean
    public JobRunrConfiguration jobRunrConfiguration(DataSource dataSource) {
        return JobRunr.configure()
            .useStorageProvider(SqlStorageProviderFactory.using(dataSource))
            .useBackgroundJobServer()
            .useDashboard(dashboardPort)
            .initialize();
    }

    /**
     * 关键：使用 JobRunr 的周期性任务选举主节点
     */
    @Recurring(
        id = "dashboard-leader-election",  // 唯一ID确保单例执行
        cron = "*/10 * * * * *"            // 每10秒检查一次
    )
    @Job(name = "Dashboard主节点选举")
    public void electDashboardLeader() {
        String instanceId = getInstanceId();

        // 尝试成为主节点
        boolean becameLeader = tryBecomeDashboardLeader(instanceId);

        if (becameLeader) {
            log.info("🎉 实例 {} 成为Dashboard主节点", instanceId);
            enableFullDashboardFeatures();
        } else {
            // 检查当前主节点是否健康
            checkLeaderHealth();
        }
    }

    /**
     * 尝试成为主节点
     * 利用 JobRunr 的单例执行保证只有一个实例执行此逻辑
     */
    private boolean tryBecomeDashboardLeader(String instanceId) {
        // 1. 检查当前是否有主节点
        String currentLeader = getCurrentLeader();

        if (currentLeader == null) {
            // 没有主节点，尝试成为主节点
            return acquireLeadership(instanceId);
        }

        // 2. 如果当前主节点是自己，续期
        if (currentLeader.equals(instanceId)) {
            renewLeadership(instanceId);
            return true;
        }

        // 3. 如果当前主节点不健康，尝试抢占
        if (!isLeaderHealthy(currentLeader)) {
            return acquireLeadership(instanceId);
        }

        return false;
    }
}

@Service
@Slf4j
public class SmartDashboardService {

    @Autowired
    private StorageProvider storageProvider;

    private static final String LEADER_METADATA_KEY = "dashboard:leader";
    private static final long LEADER_TTL_MS = 30000; // 30秒

    /**
     * 主选举任务 - 利用 JobRunr 保证单例执行
     */
    @Recurring(
        id = "dashboard-leader-election-v2",
        cron = "*/5 * * * * *"  // 每5秒执行一次
    )
    public void leaderElection() {
        String instanceId = getInstanceId();
        long now = System.currentTimeMillis();

        // 尝试获取或更新领导权
        boolean isLeader = updateLeadership(instanceId, now);

        if (isLeader) {
            onBecomeLeader(instanceId);
        } else {
            onRemainFollower(instanceId);
        }
    }

    private boolean updateLeadership(String instanceId, long timestamp) {
        try {
            // 使用 JobRunr 的 Metadata API
            Metadata leaderMetadata = storageProvider.getMetadata(LEADER_METADATA_KEY);

            if (leaderMetadata == null) {
                // 没有领导，成为领导
                leaderMetadata = new Metadata(LEADER_METADATA_KEY,
                    new LeaderInfo(instanceId, timestamp + LEADER_TTL_MS));
                storageProvider.saveMetadata(leaderMetadata);
                return true;
            }

            LeaderInfo leaderInfo = leaderMetadata.getValue(LeaderInfo.class);

            if (timestamp > leaderInfo.getExpiryTime()) {
                // 领导已过期，抢占
                leaderInfo = new LeaderInfo(instanceId, timestamp + LEADER_TTL_MS);
                leaderMetadata.setValue(leaderInfo);
                storageProvider.saveMetadata(leaderMetadata);
                return true;
            }

            if (leaderInfo.getInstanceId().equals(instanceId)) {
                // 自己是领导，续期
                leaderInfo.setExpiryTime(timestamp + LEADER_TTL_MS);
                leaderMetadata.setValue(leaderInfo);
                storageProvider.saveMetadata(leaderMetadata);
                return true;
            }

            return false;

        } catch (Exception e) {
            log.error("领导选举失败", e);
            return false;
        }
    }

    @Data
    @AllArgsConstructor
    @NoArgsConstructor
    public static class LeaderInfo {
        private String instanceId;
        private long expiryTime;
    }
}

     * Dashboard健康检查
     * 只有"健康"的Dashboard实例才会接收流量
     */
    @RestController
    @RequestMapping("/health")
    public class DashboardHealthController {

        @Autowired
        private StorageProvider storageProvider;

        @GetMapping("/dashboard")
        public ResponseEntity<?> dashboardHealth() {
            Map<String, Object> health = new HashMap<>();

            try {
                // 检查数据库连接
                storageProvider.getJobCount(JobState.ENQUEUED);

                // 检查当前负载
                int workerCount = getCurrentWorkerCount();

                health.put("status", "UP");
                health.put("instance", getInstanceId());
                health.put("workers", workerCount);
                health.put("canAcceptTraffic", workerCount < 100); // 简单负载检查
                health.put("timestamp", Instant.now());

                return ResponseEntity.ok(health);

            } catch (Exception e) {
                health.put("status", "DOWN");
                health.put("error", e.getMessage());
                return ResponseEntity.status(503).body(health);
            }
        }
    }
