一、cryptSharedLibPath是什么？
核心概念

├─────────────────────────────────────────────────────────────┤

│   ┌─────────────────────────────────────────────────────┐   │
│   │ MongoDB 驱动程序 (mongodb-driver)                   │   │

│   │  • 实际执行加解密操作                                │   │
│   │  • 与KMS通信                                         │   │

│   └─────────────────────────────────────────────────────┘   │
│                             ↓                               │
│   外部KMS (AWS KMS/Azure Key Vault/HashiCorp Vault/等)    │
└─────────────────────────────────────────────────────────────┘

cryptSharedLibPath指定了 MongoDB 加密共享库​ 的路径，这个库是字段级加密（FLE）的核心组件，负责：

实际执行加解密操作

与KMS服务通信

管理密钥缓存

实现加密算法

方案2：手动下载（无root权限）

#!/bin/bash
# download_crypt_shared.sh

# 设置版本和下载目录
VERSION="1.8.0"
OS=$(uname -s | tr '[:upper:]' '[:lower:]')
ARCH=$(uname -m)
DOWNLOAD_DIR="/opt/mongodb/crypt_shared"
LIB_PATH="$DOWNLOAD_DIR/lib/mongo_crypt_v1.so"

# 根据系统架构调整
case $ARCH in
    x86_64) ARCH="x86_64" ;;
    aarch64) ARCH="arm64" ;;
    *) echo "Unsupported architecture: $ARCH" && exit 1 ;;
esac

# 创建目录
mkdir -p $DOWNLOAD_DIR
cd $DOWNLOAD_DIR

# 下载对应平台的库
case $OS in
    linux)
        # 从MongoDB下载中心下载
        URL="https://downloads.mongodb.com/linux/libmongocrypt-linux-${ARCH}-enterprise-${VERSION}.tgz"
        curl -L -o libmongocrypt.tgz $URL
        tar -xzf libmongocrypt.tgz

        # 查找库文件
        find . -name "mongo_crypt_v1.so" -type f | head -1
        ;;

    darwin)
        # macOS版本
        URL="https://downloads.mongodb.com/osx/libmongocrypt-macos-${ARCH}-enterprise-${VERSION}.tgz"
        curl -L -o libmongocrypt.tgz $URL
        tar -xzf libmongocrypt.tgz

        # macOS使用dylib
        find . -name "mongo_crypt_v1.dylib" -type f | head -1
        ;;

    *)
        echo "Unsupported OS: $OS"
        exit 1
        ;;
esac

echo "Library downloaded to: $DOWNLOAD_DIR"
echo "Set cryptSharedLibPath to: $LIB_PATH"

动态查找库路径

import java.nio.file.*;

public class CryptLibFinder {

    public static String findCryptSharedLib() {
        String[] possiblePaths = {
            // Linux paths
            "/usr/lib/mongo_crypt_v1.so",
            "/usr/lib64/mongo_crypt_v1.so",
            "/usr/lib/x86_64-linux-gnu/mongo_crypt_v1.so",
            "/usr/local/lib/mongo_crypt_v1.so",
            // macOS paths
            "/usr/local/lib/mongo_crypt_v1.dylib",
            "/opt/homebrew/lib/mongo_crypt_v1.dylib",
            // Windows paths
            "C:\\Program Files\\MongoDB\\lib\\mongo_crypt_v1.dll",
            "C:\\mongodb\\lib\\mongo_crypt_v1.dll",
            // 自定义路径
            System.getenv("MONGODB_CRYPT_SHARED_LIB_PATH"),
            System.getProperty("mongodb.crypt.shared.lib.path"),
            // 相对路径
            "./lib/mongo_crypt_v1.so",
            "./mongo_crypt_v1.so"
        };

        for (String path : possiblePaths) {
            if (path != null && Files.exists(Paths.get(path))) {
                System.out.println("Found crypt shared library at: " + path);
                return path;
            }
        }

        throw new RuntimeException("""
            MongoDB crypt shared library not found!

            Please install it using one of these methods:

            1. For Ubuntu/Debian:
               sudo apt-get install libmongocrypt-dev

            2. For RHEL/CentOS:
               sudo yum install mongodb-enterprise-cryptd

            3. Download manually from:
               https://downloads.mongodb.com/linux/libmongocrypt-linux-x86_64-enterprise-1.8.0.tgz

            4. Or set the library path explicitly:
               - Environment variable: export MONGODB_CRYPT_SHARED_LIB_PATH=/path/to/mongo_crypt_v1.so
               - Java property: -Dmongodb.crypt.shared.lib.path=/path/to/mongo_crypt_v1.so
            """);
    }
}

@Configuration
public class MongoEncryptionConfig {

    @Bean
    public MongoClient mongoClient() {
        // 1. 从环境变量获取库路径
        String cryptLibPath = System.getenv("MONGODB_CRYPT_SHARED_LIB_PATH");

        // 2. 如果没有设置，尝试自动查找
        if (cryptLibPath == null || cryptLibPath.isEmpty()) {
            cryptLibPath = findCryptSharedLib();
        }

        // 3. 配置自动加密
        Map<String, Object> extraOptions = new HashMap<>();
        if (cryptLibPath != null && !cryptLibPath.isEmpty()) {
            extraOptions.put("cryptSharedLibPath", cryptLibPath);

            // 可选：配置其他选项
            extraOptions.put("cryptSharedLibRequired", true);  // 是否必需
            extraOptions.put("cryptSharedLibSearchPath", "/usr/lib:/usr/local/lib");
        }

        AutoEncryptionSettings autoEncryptionSettings = AutoEncryptionSettings.builder()
            .keyVaultNamespace("encryption.__keyVault")
            .kmsProviders(getKmsProviders())
            .schemaMap(getSchemaMap())
            .extraOptions(extraOptions)
            .build();

        return MongoClients.create(
            MongoClientSettings.builder()
                .applyConnectionString(new ConnectionString(mongoUri))
                .autoEncryptionSettings(autoEncryptionSettings)
                .build()
        );
    }
}

public class CryptLibDebug {

    public static void diagnoseCryptLibIssue() {
        System.out.println("=== MongoDB Crypt Shared Library Diagnostic ===");

        // 1. 检查环境变量
        System.out.println("1. Checking environment variables:");
        String envPath = System.getenv("MONGODB_CRYPT_SHARED_LIB_PATH");
        System.out.println("   MONGODB_CRYPT_SHARED_LIB_PATH = " +
            (envPath != null ? envPath : "NOT SET"));

        // 2. 检查Java属性
        String propPath = System.getProperty("mongodb.crypt.shared.lib.path");
        System.out.println("   mongodb.crypt.shared.lib.path = " +
            (propPath != null ? propPath : "NOT SET"));

        // 3. 检查库文件
        System.out.println("\n2. Checking library files:");
        checkLibrary("/usr/lib/mongo_crypt_v1.so");
        checkLibrary("/usr/lib64/mongo_crypt_v1.so");
        checkLibrary(System.getProperty("user.dir") + "/mongo_crypt_v1.so");

        // 4. 检查依赖
        System.out.println("\n3. Checking dependencies:");
        if (System.getProperty("os.name").toLowerCase().contains("linux")) {
            try {
                Process p = new ProcessBuilder("ldd", "/usr/lib/mongo_crypt_v1.so")
                    .redirectErrorStream(true)
                    .start();
                String output = new BufferedReader(
                    new InputStreamReader(p.getInputStream()))
                    .lines().collect(Collectors.joining("\n"));
                System.out.println("   Library dependencies:\n" + output);
            } catch (Exception e) {
                System.out.println("   Failed to check dependencies: " + e.getMessage());
            }
        }

        // 5. 检查权限
        System.out.println("\n4. Checking permissions:");
        String libPath = envPath != null ? envPath : "/usr/lib/mongo_crypt_v1.so";
        File libFile = new File(libPath);
        if (libFile.exists()) {
            System.out.println("   Readable: " + libFile.canRead());
            System.out.println("   Executable: " + libFile.canExecute());
            System.out.println("   Size: " + libFile.length() + " bytes");
        }
    }

    private static void checkLibrary(String path) {
        File file = new File(path);
        System.out.println("   " + path + " -> " +
            (file.exists() ? "EXISTS" : "MISSING"));
    }
}

@Slf4j
@Component
public class EncryptionHealthCheck implements HealthIndicator {

    @Value("${mongodb.encryption.enabled:false}")
    private boolean encryptionEnabled;

    @Override
    public Health health() {
        if (!encryptionEnabled) {
            return Health.up().withDetail("encryption", "disabled").build();
        }

        try {
            // 尝试加载加密库
            String libPath = System.getenv("MONGODB_CRYPT_SHARED_LIB_PATH");
            if (libPath == null) {
                return Health.down()
                    .withDetail("error", "MONGODB_CRYPT_SHARED_LIB_PATH not set")
                    .build();
            }

            File libFile = new File(libPath);
            if (!libFile.exists()) {
                return Health.down()
                    .withDetail("error", "Crypt library not found: " + libPath)
                    .withDetail("suggestion", "Install with: apt-get install libmongocrypt-dev")
                    .build();
            }

            if (!libFile.canRead()) {
                return Health.down()
                    .withDetail("error", "Cannot read crypt library: " + libPath)
                    .withDetail("suggestion", "Check file permissions")
                    .build();
            }

            // 测试加密功能
            boolean canEncrypt = testEncryptionCapability();

            return canEncrypt ?
                Health.up()
                    .withDetail("crypt_library", libPath)
                    .withDetail("status", "operational")
                    .build() :
                Health.down()
                    .withDetail("error", "Encryption test failed")
                    .build();

        } catch (Exception e) {
            return Health.down()
                .withException(e)
                .withDetail("error", "Encryption health check failed")
                .build();
        }
    }
}

@Configuration
@Slf4j
public class CryptLibMonitor {

    @EventListener(ApplicationReadyEvent.class)
    public void logCryptLibInfo() {
        String libPath = System.getenv("MONGODB_CRYPT_SHARED_LIB_PATH");
        File libFile = libPath != null ? new File(libPath) : null;

        if (libFile != null && libFile.exists()) {
            log.info("MongoDB Crypt Shared Library loaded from: {}", libPath);
            log.info("Library size: {} bytes, last modified: {}",
                libFile.length(),
                new Date(libFile.lastModified()));

            // 记录库版本
            try {
                Process process = new ProcessBuilder("strings", libPath, "|", "grep", "libmongocrypt")
                    .redirectErrorStream(true)
                    .start();
                String versionInfo = new BufferedReader(
                    new InputStreamReader(process.getInputStream()))
                    .lines().collect(Collectors.joining("\n"));
                log.info("Library info: {}", versionInfo);
            } catch (IOException e) {
                log.warn("Could not read library version: {}", e.getMessage());
            }
        } else {
            log.warn("MongoDB Crypt Shared Library not found at: {}", libPath);
            log.warn("Field-level encryption will not be available");
        }
    }
}
八、常见错误和解决方案
错误1：库文件不存在
复制
错误信息：Failed to load crypt shared library: /usr/lib/mongo_crypt_v1.so
原因：库文件未安装或路径错误
解决：
1. 安装库：sudo apt-get install libmongocrypt-dev
2. 或指定正确路径：export MONGODB_CRYPT_SHARED_LIB_PATH=/实际路径
3. 或下载库文件到项目目录
错误2：权限不足
复制
错误信息：Permission denied while loading shared library
原因：库文件权限不正确
解决：
sudo chmod 755 /usr/lib/mongo_crypt_v1.so
sudo chown root:root /usr/lib/mongo_crypt_v1.so
错误3：缺少依赖
复制
错误信息：error while loading shared libraries: libssl.so.1.1: cannot open shared object file
原因：缺少OpenSSL库
解决：
sudo apt-get install libssl1.1
错误4：版本不匹配
复制
错误信息：libmongocrypt version mismatch
原因：库版本与驱动程序不兼容
解决：

总结

cryptSharedLibPath是指定 MongoDB字段级加密核心库​ 路径的配置。正确配置它需要：

安装库文件：通过包管理器或手动下载

设置路径：通过环境变量、Java属性或代码指定

验证可用性：确保应用程序有权限访问

监控健康：在生产环境中持续监控

最简单的解决方案：

bash
复制
# 1. 安装
sudo apt-get install libmongocrypt-dev

# 2. 设置环境变量
export MONGODB_CRYPT_SHARED_LIB_PATH=/usr/lib/mongo_crypt_v1.so

# 3. 启动应用
java -jar your-application.jar

这样配置后，MongoDB驱动程序就能找到加密库，并与HashiCorp Vault等KMS服务配合，实现完整的字段级加密功能。
