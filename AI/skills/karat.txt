Karat（karat.com）平台介绍
Karat 是面向企业的技术人才评估与招聘外包服务商（人才提升合作伙伴），主打Interviewing Cloud 面试云，聚焦工程师技术面试，适配人机协同（Human+AI）时代，帮企业解决技术招聘标准不统一、占用内部工程师大量时间、AI 能力测评难的痛点。简单说：企业把工程师的技术面试外包给 Karat，由它的专业面试工程师完成评估，并输出人才数据分析报告。
核心业务
直接招聘（Direct Hiring）：全球标准化筛选技术人才，替企业完成技术面试环节。
合作人才评估（Partner Talent）：评估外包人员、IT 服务商的工程师，确保外包人员能力匹配企业标准。
AI 就绪度评估（AI Readiness）：测评在职、候选工程师使用 AI 工具工作的实际能力，采用真实 AI 实战场景考核。
多元化人才项目 Brilliant Black Minds：为黑人软件工程师提供免费模拟技术面试，丰富企业人才管道，促进招聘公平。
完整工作流程四步
设定统一标准：和企业一起定义工程师能力标准，确定招聘门槛。
专业人才测评：Karat 专属面试工程师，用统一流程评估候选人，保证数据可对比。
全球人才质量对标：依托超过 60 万次技术面试数据库，把企业人才和行业基准对比。
数据驱动决策：面试数据用于正式招聘、外包人员上岗、项目人员分配决策。
平台主要特点
统一、标准化的技术面试
由 Karat 专业的 Interview Engineer（面试工程师）执行面试，不受团队、地域、外包供应商差异影响，所有候选人执行同一套严格考核标准，消除不同面试官带来的主观偏差。企业内部工程师不用花大量时间做初筛面试，释放研发人力投入产品开发。
海量数据与行业对标能力
积累60 万 + 场技术面试数据，给企业提供人才洞察、市场基准对比，企业能看清自身工程师、外包人员在行业中的水平。输出可横向对比的客观评估结果，不是模糊主观评价。
支持 AI 时代工程师测评
提供真实的 AI 原生实战场景与专业方法论，评估工程师和 AI 协同工作的能力，不需要消耗企业内部团队精力，专门应对当下 AI 工具普及后的人才考核需求。
产品覆盖全职 + 外包人才
不仅招正式员工，还可以评估承包商、IT 服务商外派人员，给外包人员做能力把关，给企业提供人才质量保障。
多元化公益项目
Brilliant Black Minds 项目，为科技行业少数群体工程师提供免费模拟面试，拓展企业多元化人才池。
客户群体
服务大量大型企业（Mastercard、Deliveroo、EA、Compass 等），客户反馈：可以加快招聘进度、节省工程师工时、统一招聘口径。

输出标准化面试反馈、人才质量数据报告、跨地域 / 岗位对标分析，支撑企业招聘决策、外包准入、团队人员优化，让每一份人才预算产出更高价值。

一、Karat 高频 Java 面试题 + 英文参考回答
适配 Karat 英文技术面试，回答简洁，符合面试口述长度，适合背诵练习；全部为 Karat 经常问到的 Java 基础 / OOP / 集合 / JVM 考点。
1. What is the difference between ArrayList and LinkedList?
Answer:
ArrayList is backed by an underlying array. It provides fast random‑access by index, but adding or removing elements in the middle is slow because elements need to be shifted.
LinkedList is a doubly‑linked list. Random access is slow, but insertion and deletion at both ends are efficient.
For most general‑purpose scenarios, ArrayList is preferred.
中文参考：ArrayList 底层数组，随机访问快，中间增删慢；LinkedList 双向链表，随机访问慢，首尾增删高效；绝大多数场景优先 ArrayList。
2. How does HashMap work in Java?
Answer:
HashMap stores key‑value pairs. It calculates the hash code of the key to decide the bucket index.
When hash collision happens, multiple entries are stored in one bucket. Before Java 8 it uses a linked list. Starting from Java 8, when the threshold is reached, the linked list converts to a red‑black tree to speed‑up lookup.
Keys must override equals() and hashCode() correctly.
中文参考：HashMap 基于 key 的 hashCode 定位桶下标；发生哈希冲突时，Java8 前用链表，Java8 链表长度阈值超过后转为红黑树提升查询效率；key 必须正确重写 equals 和 hashCode。
3. What is the difference between String, StringBuilder and StringBuffer?
Answer:
String is immutable. Every modification creates a new object.
StringBuilder is mutable and not thread‑safe, good for single‑thread string concatenation.
StringBuffer is mutable and thread‑safe because its methods are synchronized, so it has worse performance.
中文参考：String 不可变，每次修改生成新对象；StringBuilder 可变、非线程安全，单线程拼接优先使用；StringBuffer 可变、加 synchronized 线程安全，性能更低。
4. What are checked and unchecked exceptions?
Answer:
Checked exceptions must be declared in method signature or caught by try‑catch at compile time, for example IOException.
Unchecked exceptions extend RuntimeException. They are validated at runtime, we do not have to catch or declare them, such as NullPointerException.
中文参考：受检异常编译期强制捕获或声明抛出，例如 IOException；非受检异常继承 RuntimeException，运行时抛出，不必强制处理，例如空指针异常。
5. What is the difference between heap and stack in JVM?
Answer:
The stack stores local variables and method call frames. Each thread has its own stack, memory is freed when method returns.
The heap is shared by all threads, it stores all Java objects and arrays. Garbage Collection works mainly on the heap to reclaim unused memory.
中文参考：栈属于线程私有，存放局部变量、方法栈帧，方法结束自动释放；堆线程共享，存放对象、数组，GC 主要回收堆内存。
6. What are the four main OOP principles?
Answer:
Encapsulation: hide internal state and expose public methods.
Inheritance: child class reuses and extends parent class code.
Polymorphism: same method behaves differently for different sub‑class instances.
Abstraction: hide implementation details via abstract classes or interfaces.
中文参考：封装：隐藏内部状态，对外暴露方法；继承：子类复用扩展父类；多态：同一方法不同子类实例行为不同；抽象：抽象类 / 接口隐藏实现细节。
7. What is the difference between == and equals()?
Answer:
== compares memory reference for objects, or raw value for primitive types.
equals() is a method from Object class. By default it uses reference comparison, but many classes like String override equals() to compare actual content.
中文参考：==对于基本类型比较值，对象比较内存引用；equals 是 Object 方法，默认比较引用；String 等类重写用来比较内容。
二、模拟 Karat 算法面试题（Java）
Karat Core 面试真实风格：中等难度，要求：沟通题目 → 分析边界 case → 讲思路 + 复杂度 → Java 编码 → 测试用例。
题目类型：数组哈希，Karat 非常高频。
Problem：Two Sum 变种
Description（英文原题，面试看到就是这个）
Given an integer array nums and an integer target, return indices of the two numbers such that they add up to target.
You may assume each input has exactly one solution. You cannot use the same element twice.
Return the result as an int array.
Sample Input 1:
nums = {2,7,11,15}, target = 9
Sample Output: {0,1}
Edge cases you need to consider:
null input array
array length less than 2
✅面试口述思考流程（英文示范，Karat 重点看这个）
面试时你要口头说出下面这段话，再写代码
“So we need to find two different indices whose values sum to target. Exactly one solution exists.
First I should handle edge cases: if array is null or length < 2, return empty array.
Brute‑force is two nested loops with O (n²) time. We can optimize by using HashMap.
We store number and its index in HashMap. For each element, calculate complement = target‑current value.
If complement exists in map, return stored index and current index. Otherwise put current value and index into map.
Time complexity is O (n), space complexity O (n).”
Java 参考代码（Karat 在线 IDE 可直接运行）
java
import java.util.HashMap;
import java.util.Map;

public class TwoSumKarat {
    public int[] twoSum(int[] nums, int target) {
        // handle edge case
        if(nums == null || nums.length < 2){
            return new int[]{};
        }

        Map<Integer, Integer> map = new HashMap<>();
        for(int i = 0; i < nums.length; i++){
            int complement = target - nums[i];
            if(map.containsKey(complement)){
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        // per problem statement, exactly one solution exists, this line won't hit
        return new int[]{};
    }
}
面试写完代码之后口述测试（英文示范）
“Let me walk through sample test case. nums = [2,7,11,15], target=9.
i=0, num=2, complement=7, map does not contain 7, put (2,0).
i=1, num=7, complement=2, map has key 2 with index 0. Return [0,1]. Correct.”
